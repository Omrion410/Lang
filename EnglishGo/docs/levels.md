# EnglishGo - Learning Levels

# Overview

This document defines the complete learning progression used by EnglishGo.

The application follows the Common European Framework of Reference for Languages (CEFR), allowing learners to progress from complete beginners to advanced English proficiency.

---

# Level Structure

EnglishGo supports six primary levels:

* A1 – Beginner
* A2 – Elementary
* B1 – Intermediate
* B2 – Upper Intermediate
* C1 – Advanced
* C2 – Proficient

Each level unlocks only after completing the previous level.

---

# A1 – Beginner

Objectives:

* Learn the alphabet
* Basic pronunciation
* Greetings
* Numbers
* Colors
* Days and Months
* Family
* Food
* Daily Activities
* Basic Questions

Expected Vocabulary:

500 words

Lessons:

Approximately 100

# Lesson Progression

Each lesson contains:

* Introduction
* Learning Content
* Practice
* Quiz
* Review
* Reward

---

# Unlock System

Users unlock:

* New Lessons
* New Topics
* New Challenges
* New Badges

by completing previous content.

---

# Level Completion

Each level requires:

* Minimum lesson completion percentage
* Quiz success rate
* Vocabulary mastery
* Review completion

---

# Rewards

Completing a level grants:

* XP Bonus
* Coins
* Achievement Badge
* Level Certificate (Future)

---

# Future Expansion

Future levels may include:

* English for Children

---

# Design Principles

The level system should always be:

* Progressive
* Motivating
* Balanced

* Measurable
