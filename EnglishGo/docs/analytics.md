# EnglishGo - Analytics

# Overview

This document defines the analytics system used by the EnglishGo application.

The analytics system helps measure user behavior, learning performance, application growth, and business performance while respecting user privacy.

---

# Objectives

The analytics system should:

* Measure user engagement.
* Improve learning efficiency.
* Monitor application performance.
* Track revenue.
* Support business decisions.
* Protect user privacy.

---

# User Analytics

Track:

* Daily Active Users (DAU)
* Monthly Active Users (MAU)
* New Registrations
* Returning Users
* Session Duration
* Session Frequency

---

# Learning Analytics

Track:

* Lessons Started
* Lessons Completed
* Lesson Completion Rate
* Quiz Scores
* Vocabulary Mastered
* Grammar Progress
* Speaking Practice
* Listening Practice

---

# Progress Analytics

* Time Spent Learning
* Weekly Progress
* Monthly Progress

---

# Business Analytics

Monitor:

* Total Revenue
* Active Subscribers
* Advertisement Revenue

---

# Privacy

The analytics system should:

* Avoid unnecessary personal data collection.
* Store only required information.
* Respect user privacy.
* Follow applicable privacy regulations.
* Allow users to manage analytics preferences where required.
