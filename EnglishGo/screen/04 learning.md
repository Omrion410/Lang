# EnglishGo - Learning Screen

# Purpose

The Learning Screen is the core educational section of EnglishGo.

It provides structured English lessons, interactive exercises, quizzes, AI-powered speaking practice, and personalized learning paths.

---

# Objectives

* Teach English Effectively
* Support All Skill Levels
* Encourage Daily Practice
* Improve Speaking Confidence
* Personalize Learning

---

# Learning Categories

Display:

* Vocabulary
* Grammar
* Speaking
* Listening
* Reading
* Writing

---

# Lesson Structure

Each lesson includes:

* Lesson Title
* Difficulty Level
* Estimated Duration
* Learning Objectives
* Interactive Content

---

# Exercises

Support:

* Multiple Choice
* Fill in the Blank
* Matching
* Listening Practice
* Pronunciation Practice
* Sentence Building

---

# AI Speaking Coach

Users can:

* Read Sentences
* Record Their Voice
* Receive Pronunciation Score
* View Word-Level Feedback
* Repeat Difficult Words
* Track Speaking Improvement

---

# Quiz System

Each lesson ends with:

* Knowledge Quiz
* Speaking Evaluation
* Lesson Score
* AI Feedback

---

# Learning Progress

Display:

* Lesson Completion
* Skill Progress
* Current Level
* Accuracy Rate
* Speaking Score
