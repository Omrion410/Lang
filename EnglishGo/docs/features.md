# EnglishGo - Features

# Overview

This document defines the functional features of the EnglishGo application.

The application is designed to deliver a complete English learning experience through interactive lessons, personalized progress tracking, gamification, and AI-assisted learning.

---

# User Account

Users can:

* Register using Email
* Sign in with Google
* Sign in with Apple (Future)
* Reset Password
* Verify Email
* Manage Profile
* Delete Account

---

# User Profile

Each profile includes:

* Profile Picture
* Full Name
* Username
* Learning Level
* Country
* Native Language
* Daily Goal
* Learning Statistics

---

# Placement Test

New users may choose to:

* Start as Beginner
* Take a Placement Test
* Select their preferred learning level manually

---

# Learning Levels

Supported levels:

* Beginner (A1)
* Elementary (A2)
* Intermediate (B1)
* Upper Intermediate (B2)
* Advanced (C1)
* Fluent (C2)

---

# Lessons

Lessons include:

* Vocabulary
* Grammar
* Reading
* Listening
* Speaking
* Writing
* Pronunciation

Each lesson contains:

* Explanation
* Interactive Exercises
* Review
* Final Quiz

# Exercises

Exercise types include:

* Multiple Choice
* Fill in the Blank
* Word Matching
* Sentence Building
* Listening Exercises
* Speaking Practice
* Image Recognition
* Pronunciation Practice
