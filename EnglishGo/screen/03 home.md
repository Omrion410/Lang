# EnglishGo - Home Screen

# Purpose

The Home Screen is the main dashboard of EnglishGo.

It provides quick access to lessons, AI features, learning progress, daily goals, and premium services.

---

# Objectives

* Quick Access to Learning
* Continue Last Lesson
* Daily Motivation
* Display Learning Progress
* Easy Navigation

---

# Screen Components

Display:

* Welcome Message
* User Name
* Daily Streak
* Daily Goal
* Continue Learning Button
* Current Level
* Learning Progress
* AI Speaking Coach Shortcut
* Premium Banner (If Applicable)
* Bottom Navigation Bar

---

# Learning Sections

Provide access to:

* Vocabulary
* Grammar
* Speaking
* Listening
* Reading
* Writing

---

# Quick Actions

Users can quickly:

* Continue Last Lesson
* Start Daily Challenge
* Practice Speaking
* Open AI Conversation
* Review Mistakes

---

# Daily Motivation

Display:

* Daily Quote
* Learning Reminder
* Daily Challenge
* Achievement Progress

---

# Premium Promotion

Non-premium users may see:

* Free Trial Reminder
* Premium Features
* Upgrade Button

Premium users should not see promotional banners.

---

# Navigation

Bottom Navigation:

* Home
* Learn
* Progress
* Profile

---

# Accessibility

Support:

* Screen Readers
* Large Text
* High Contrast
* Reduced Motion

---

# Design Principles

The Home Screen should always remain:

* Clean
* Motivating
* Fast
* Simple
* Informative
* Future Ready
