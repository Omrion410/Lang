# EnglishGo

EnglishGo is a modern English-learning application designed to help people from different language backgrounds learn English through interactive lessons, exercises, speaking practice, and AI-powered feedback.

## Target Users

EnglishGo is designed for learners whose first languages include:

* Arabic
* French
* Spanish
* Indonesian

The learning language is **English**.

## Core Features

* Vocabulary
* Grammar
* Speaking
* Listening
* Reading
* Writing
* Interactive Exercises
* Quizzes
* Learning Progress
* Achievements
* Learning Streaks
* AI Speaking Coach
* Pronunciation Evaluation
* AI Conversations
* Personalized Learning

## AI Speaking Coach

The AI Speaking Coach allows users to:

* Speak English sentences.
* Receive pronunciation analysis.
* Receive a pronunciation score.
* Identify pronunciation mistakes.
* Receive corrections.
* Repeat difficult words.
* Track speaking improvement.

## Monetization

EnglishGo uses a freemium model.

New users receive a limited Premium trial period.

Premium features may include:

* Advanced AI Speaking Coach
* Advanced Pronunciation Analysis
* AI Conversations
* Advanced Analytics
* Ad-Free Experience

Subscriptions are managed through official app-store payment systems.

## Advertising

Advertisements should be:

* Family Friendly
* Educational
* Respectful
* Non-Intrusive

Inappropriate advertisements should be filtered whenever possible.

## Technology

The project is divided into:

* `mobile` — mobile application code
* `backend` — backend services
* `assets` — application assets
* `docs` — project documentation
* `screens` — screen specifications
* `business` — business specifications

## Project Goal

Build a simple, useful, scalable English-learning application that can generate revenue and potentially become part of the Omrion ecosystem in the future.

## Development Principle

Start with a simple MVP, launch quickly, test with real users, improve based on feedback, and continuously expand the application.
